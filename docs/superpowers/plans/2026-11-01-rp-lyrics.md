# Radio Paradise lyrics

Replace the external lyrics provider with RP, then test, commit, push, and deploy.

- Collect `/api/nowplaying_list_v2022?mode=wip-channel` instead of `/api/now_playing`. Keep the same
  bounded 30-second per-channel cache and persist RP song IDs and duration.
- Fetch `/siteapi.php?file=music::song&song_id=...` on demand. Convert RP lyric
  HTML into plain text and retain source attribution and database retry TTLs.
- Resolve older rows against the cached recent RP history with exact metadata
  matching. RP library search requires cookie authentication, so do not add an
  account dependency. Older rows outside recent history gain their ID on replay.
- Refresh earlier provider results on first opening after the update; preserve
  cached lyrics on provider failures only when they already came from RP.
- Verify HTTP mapping, history resolution, text conversion, persistence,
  caching, and live browser behavior. Back up production before deployment.
